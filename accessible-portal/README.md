# accessible-portal

A student help chatbot in English, Hindi and Gujarati, with an on-screen keyboard for each script, read-aloud, large-text and high-contrast modes, and a "due soon" notices list. Static page, no backend, demo data only.

```bash
npm test      # unit tests for the chatbot and notice logic
npm start     # serves the folder, then open the printed URL
```

Also published on GitHub Pages: https://sksiddhant.github.io/portfolio/accessible-portal/
